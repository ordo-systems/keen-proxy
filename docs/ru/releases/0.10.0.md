# 0.10.0 — каталог пресетов и маршрутизация

**Выпущена 2026-11-25.** [История версий](index.md) · [Релиз и файлы на GitHub](https://github.com/ordo-systems/keen-proxy/releases/tag/v0.10.0)

- Каталог пресетов встраивается из закреплённого релиза. При сборке и на роутере скачивать каталог не нужно. В панели пресеты показаны в таблице с категориями и поиском; пользовательские пресеты выделены в отдельный раздел. Идентификаторы прежних пресетов и ручные исключения сохраняются. Подробнее — [в руководстве пользователя](../user-guide.md).
- В правилах можно использовать суффиксы доменов верхнего уровня. См. [PR #53](https://github.com/ordo-systems/keen-proxy/pull/53).
- Профили AmneziaWG принимают `on`/`off` наряду с `true`/`false` и `1`/`0`. См. [PR #57](https://github.com/ordo-systems/keen-proxy/pull/57).

Панель этой версии всё ещё использует старый установщик. Если обновление прерывается при добавлении защитного правила, следуйте [инструкции для 0.10.1](0.10.1.md#entware-update-recovery).

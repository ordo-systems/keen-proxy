# 0.9.1 — upgrading from 0.9.0

Released **2026-11-18**. This update reduces WireGuard and AmneziaWG receive memory under load, improves compatibility with older Entware tools, and adds DNS and rule-list controls.

[Version history](index.md) · [GitHub release and downloads](https://github.com/ordo-systems/keen-proxy/releases/tag/v0.9.1)

## WireGuard and AmneziaWG

- [#40](https://github.com/ordo-systems/keen-proxy/pull/40): queued receive packets use packet-sized buffers on routers rather than holding full-size UDP receive slots. Large read buffers stay separate; transmit is unchanged. The savings depend on traffic and are not a hard memory limit.

## DNS and rule lists

- [#42](https://github.com/ordo-systems/keen-proxy/pull/42): you can configure a single DNS upstream in Settings or imported YAML. The secondary resolver is optional.
- [#43](https://github.com/ordo-systems/keen-proxy/pull/43): allow individual LAN resolvers to bypass DNS interception by source IPv4 address. The exception covers UDP and TCP port 53 only; it does not disable interception for other traffic or other clients.
- [#45](https://github.com/ordo-systems/keen-proxy/pull/45): import and export group and local preset lists in TXT, CSV, KeenProxy JSON, sing-box source JSON, and SRS. Preview imports before accepting them into the draft; **Apply** activates the changes.

## Entware compatibility and upgrade

- [#44](https://github.com/ordo-systems/keen-proxy/pull/44): if legacy `iptables-restore` explicitly rejects `-w`, KeenProxy retries without that flag but keeps `--noflush` so unrelated rules are preserved. This does not make an unavailable kernel TPROXY target usable.
- Use the [installation and update guide](../getting-started.md#install-or-update-from-github). If restore now reports `line N failed`, see [Keenetic TPROXY troubleshooting](../troubleshooting.md#keenetic-tproxy-apply); the line number alone does not identify the cause.

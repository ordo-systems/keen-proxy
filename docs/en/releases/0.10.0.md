# 0.10.0 — preset catalog and routing

**Released on 2026-11-25.** [Version history](index.md) · [GitHub release and downloads](https://github.com/ordo-systems/keen-proxy/releases/tag/v0.10.0)

- The preset catalog is embedded from a pinned release. No catalog download is required at build time or on the router. The panel shows presets in a searchable table with categories and a separate section for local presets. Existing preset IDs and manual exclusions are preserved. See [presets in the user guide](../user-guide.md#4-try-a-preset).
- Rules can match top-level domain suffixes. See [PR #53](https://github.com/ordo-systems/keen-proxy/pull/53).
- AmneziaWG profiles accept `on`/`off` alongside `true`/`false` and `1`/`0`. See [PR #57](https://github.com/ordo-systems/keen-proxy/pull/57).

The panel in this release still uses the older updater. If it rejects a forwarding guard, follow the [0.10.1 recovery instructions](0.10.1.md#entware-update-recovery).

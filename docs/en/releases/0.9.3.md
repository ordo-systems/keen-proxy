# 0.9.3 — update protection

**Released on 2026-11-21.** [Version history](index.md) · [GitHub release and downloads](https://github.com/ordo-systems/keen-proxy/releases/tag/v0.9.3)

- The updater attempts to block forwarded traffic while replacing the service. This protects client traffic from bypassing KeenProxy during a restart. The release also limits host previews. See [PR #49](https://github.com/ordo-systems/keen-proxy/pull/49).
- Failed client rule-set writes are retried. See [PR #51](https://github.com/ordo-systems/keen-proxy/pull/51).

The installer in this release aborts if it cannot apply the required forwarding guard. If an update from its panel fails for that reason, use the [0.10.1 recovery instructions](0.10.1.md#entware-update-recovery).

# История версий

Изменения для пользователей, совместимость и рекомендации по обновлению для каждого выпуска. История начинается с перехода **с 0.8.0 на 0.9.0**; более ранние заметки доступны в [GitHub Releases](https://github.com/ordo-systems/keen-proxy/releases).

| Версия | Статус | Изменения |
| --- | --- | --- |
| [0.9.0](0.9.0.md) | Выпущена | AWG, встроенный TrustTunnel, включение и отключение соединений и правил, нативное обновление OpenWrt, сборки x86, проверки памяти при сборке и поиск секретов. |
| [0.8.0](https://github.com/ordo-systems/keen-proxy/releases/tag/v0.8.0) | Выпущена 2026-11-10 | Исходная версия для обновления. Добавлены необязательные вызовы NDM для восстановления правил firewall на совместимых прошивках Keenetic/Netcraze в дополнение к периодическому сторожу. |

!!! note "Файлы релиза"
    Для установки и обновления используйте релиз по тегу в GitHub и полный комплект его файлов с контрольными суммами. Копия `main` не заменяет бинарник релиза.

Перед обновлением прочитайте раздел о совместимости и миграции для нужной версии и [инструкцию по установке и обновлению](../getting-started.md#install-or-update-from-github). Для нативного OpenWrt используйте [отдельную инструкцию](../getting-started.md#native-openwrt-installation).

# 0.9.3 — защита при обновлении

**Выпущена 2026-11-21.** [История версий](index.md) · [Релиз и файлы на GitHub](https://github.com/ordo-systems/keen-proxy/releases/tag/v0.9.3)

- Установщик пытается заблокировать транзитный трафик при замене службы, чтобы он не прошёл мимо KeenProxy во время перезапуска. Также ограничен размер предпросмотра списка хостов. См. [PR #49](https://github.com/ordo-systems/keen-proxy/pull/49).
- После ошибки записи списка правил клиента KeenProxy повторяет запись. См. [PR #51](https://github.com/ordo-systems/keen-proxy/pull/51).

Установщик этой версии прерывает обновление, если не удаётся поставить обязательное защитное правило. При такой ошибке в панели используйте [инструкцию для 0.10.1](0.10.1.md#entware-update-recovery).
